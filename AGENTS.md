This is the **JNOOOBY/JNOOOBY** GitHub profile repository. Its primary purpose is to display a profile README on the [JNOOOBY GitHub profile page](https://github.com/JNOOOBY). The `README.md` file in the root of this repository is rendered directly on the profile.

## Repository Structure

- `README.md` — The profile README displayed on the GitHub profile page.
- `.github/agents/` — GitHub Copilot agent configuration.
- `AGENTS.md` — This file; guidance for AI coding agents working in this repository.

## Conventions

- **Language**: The profile README uses Arabic (مرحباً) as the greeting. Preserve the existing language choices when making edits.
- **Content**: This repository contains no application code, build system, or tests. Changes are limited to Markdown and configuration files.
- **Formatting**: Use standard GitHub-flavored Markdown.

## Working in This Repository

- There is no build step, linter, or test suite to run.
- Changes to `README.md` are immediately visible on the GitHub profile after merging.
- Keep commits focused and descriptive since the repository is public-facing.
